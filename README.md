# ssts-integrated-webapp

A Spring Boot and Thymeleaf website for Sandy Springs Tamil School.

## Run

```sh
./gradlew bootRun
```

Then visit http://localhost:8081. Set `PORT` before starting the app to use a different port.

## Test

```sh
./gradlew test
```

The supplied school logo is sourced from the existing public school website. Public location, schedule, and welcome copy are based on the current site.
